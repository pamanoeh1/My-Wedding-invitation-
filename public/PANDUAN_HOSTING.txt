================================================================================
PANDUAN LENGKAP UPLOAD WEBSITE UNDANGAN PERNIKAHAN KE WEB HOSTING
================================================================================

Website undangan pernikahan digital ini adalah berkas Static Web (HTML, CSS, JS)
yang 100% mandiri, responsif, cepat, dan siap diunggah ke semua jenis hosting
(Cloudflare Pages / Workers, cPanel, Hostinger, Niagahoster, DomaiNesia, Rumahweb,
IDwebhost, Netlify, Vercel, GitHub Pages, dll).

--------------------------------------------------------------------------------
OPSI 1: UPLOAD KE CLOUDFLARE (Pages / Workers) - GRATIS & SANGAT CEPAT
--------------------------------------------------------------------------------
Metode A: Melalui Dashboard Cloudflare Pages (Drag & Drop):
1. Buka dashboard Cloudflare (dash.cloudflare.com) > "Workers & Pages".
2. Klik "Create Application" > tab "Pages" > "Upload assets".
3. Beri nama proyek Anda (misal: "my-wedding-invitation").
4. Ekstrak file "undangan-pernikahan-hosting.zip" di komputer Anda.
5. Drag & drop folder hasil ekstrak tersebut ke layar Cloudflare.
6. Klik "Deploy site". Website langsung online di domain *.pages.dev!

Metode B: Melalui Wrangler CLI:
1. Pastikan folder output adalah ./dist (telah menyertakan wrangler.toml).
2. Jalankan: `npx wrangler deploy`
3. Cloudflare akan membaca konfigurasi:
   not_found_handling = "single-page-application"
   tanpa aturan _redirects yang menyebabkan infinite loop (Error 100324 telah teratasi).

--------------------------------------------------------------------------------
OPSI 2: UPLOAD KE CPANEL / SHARED HOSTING (Paling Umum)
--------------------------------------------------------------------------------
1. Masuk ke cPanel akun hosting Anda (misal: domainanda.com/cpanel).
2. Buka menu "File Manager".
3. Masuk ke folder "public_html" (atau folder subdomain Anda).
4. Klik tombol "Upload" di menu atas.
5. Unggah berkas "undangan-pernikahan-hosting.zip".
6. Setelah selesai diunggah (100%), klik kanan pada berkas zip tersebut,
   lalu pilih "Extract" / "Ekstrak di sini".
7. Pastikan file "index.html" dan folder "assets" berada langsung di dalam
   folder public_html (bukan di dalam subfolder ekstraksi).
8. Selesai! Buka domain Anda di browser: https://domainanda.com


--------------------------------------------------------------------------------
OPSI 3: UPLOAD KE HOSTINGER (hPanel)
--------------------------------------------------------------------------------
1. Masuk ke dashboard Hostinger -> Web Hosting -> Kelola.
2. Buka menu "File Manager".
3. Masuk ke folder "public_html".
4. Klik tombol "Unggah" (Upload) -> pilih berkas "undangan-pernikahan-hosting.zip".
5. Klik kanan pada file zip -> pilih "Ekstrak" (Extract).
6. Selesai! Website langsung aktif di domain Anda.


--------------------------------------------------------------------------------
OPSI 4: UPLOAD KE HOSTING GRATIS (Netlify / Vercel)
--------------------------------------------------------------------------------
1. Buka https://app.netlify.com/drop
2. Drag & drop folder hasil ekstrak zip ini ke layar browser Netlify.
3. Dalam 5 detik, website langsung online dengan link HTTPS gratis!
   Anda juga bisa menghubungkan domain kustom sendiri secara gratis.


--------------------------------------------------------------------------------
CARA PENGGUNAAN FITUR:
--------------------------------------------------------------------------------
1. MEMBAGIKAN UNDANGAN KE TAMU DENGAN NAMA KHUSUS:
   Tambahkan parameter "?to=Nama+Tamu" di belakang URL domain Anda.
   Contoh:
   - https://domainanda.com/?to=Bpk.+Ir.+Hendra+Gunawan
   - https://domainanda.com/?to=dr.+Amanda+%26+Partner
   - https://domainanda.com/?to=Sahabat+Keluarga+Bambang

2. MEMBUKA PANEL EDIT PENGELOLA (ADMIN):
   Akses URL dengan parameter rahasia:
   https://domainanda.com/?salam2408&risa1211
   
   Akun Default Admin:
   - Username: admin
   - Password: wedding2026
   (Username & password dapat diubah langsung dari dalam panel edit).

3. BERKAS STANDALONE HTML (SINGLE-FILE):
   File "wedding-invitation-standalone.html" adalah versi 1 berkas tunggal terpadu
   yang dapat dibuka langsung di laptop/HP tanpa internet sekalipun.

Semoga acara pernikahan berjalan lancar, berkah, dan penuh kebahagiaan!
